# CAN sniffer — этап 2

## Реализованный инкремент: список нод

- отдельная FreeRTOS-задача анализатора и статическая очередь на 128 CAN-кадров;
- распознавание стандартных 11-битных COB-ID predefined connection set:
  NMT, SYNC, EMCY, TIME, PDO1–PDO4, SDO, heartbeat/node guarding и LSS;
- извлечение `node_id` только там, где он определяется однозначно;
- фиксированная таблица 127 нод и кольцевая история 512 событий без динамической памяти;
- snapshot API между анализатором и единственной GUI-задачей;
- вкладка `Nodes` с временем захвата, количеством уникальных нод, счётчиком
  кадров ноды, долей от общего CAN-трафика, SDO response ratio и типом
  последнего сообщения;
- сортировка по заголовкам всех столбцов и виртуализация видимых строк;
- переход кнопкой в последнем столбце на экран событий выбранной ноды;
- фильтрация событий по `node_id`, сортировка, touchscreen-прокрутка,
  виртуализация строк и пауза GUI-snapshot без остановки анализатора;
- отдельный режим `OBJ` с фиксированным hash-пулом уникальных SDO-объектов по
  ключу `node_id + index + subindex + направление`; повторный доступ обновляет
  timestamp и данные строки;
- в `OBJ` строки упорядочены по object/subindex, запрос отображается перед
  ответом; ответ содержит latency последней сопоставленной пары в микросекундах;
- прокрутка в `OBJ` не включает паузу, snapshot останавливается только отдельной
  кнопкой Pause;
- dependency-free host-side тестовые векторы для CANopen-декодера в `tests/`.
- русскоязычный экран `Информация` со справкой по режимам и типам пакетов.
- кнопка сброса на главном экране очищает статистику, историю кадров, ошибки и
  начинает отсчёт времени заново.

Текущая версия: **2.5.5**.

Глобальные сообщения без однозначного `node_id` (broadcast NMT, SYNC, TIME,
LSS) распознаются декодером, но не создают строку ноды. Extended CAN и COB-ID,
не входящие в predefined connection set, в список нод не попадают.

Детальный SDO state machine, таблица уникальных объектов, timeout/latency и
агрегированная статистика шины относятся к следующим инкрементам этапа 2.
