# CanSniff Log Analyzer

Графическая программа для просмотра и обработки логов, записанных устройством
CanSniff на карту памяти. Работает на стандартном Python 3 без установки
сторонних пакетов и открывает карту только для чтения.

## Запуск в Windows

1. Вставьте карту памяти. По умолчанию программа ищет логи в
   `G:\CANSNIFF\LOGS`.
2. Дважды щёлкните `CanSniff_Log_Analyzer.exe`. Устанавливать Python не нужно.
3. Если буква диска отличается, нажмите **Обзор…** и выберите папку
   `CANSNIFF` либо `LOGS`.

`CanSniff_Log_Analyzer.pyw` — версия для запуска из исходного кода. Расширение
`.pyw` обозначает графический Python-скрипт, который запускается без окна
консоли и требует установленный Python. Обычному пользователю достаточно EXE.

Можно передать путь явно:

```powershell
python app.py "G:\CANSNIFF"
```

Готовая сборка `CanSniff_Log_Analyzer.exe` не требует установленного Python.

## Возможности

- список всех сессий и автоматический выбор последней;
- проверка CRC заголовков, блоков, payload и footer;
- общая статистика: кадры, длительность, CAN ID, узлы, типы CANopen;
- приблизительная оценка загрузки CAN-шины;
- таблица кадров с временем и интервалом;
- сортировка по любой колонке нажатием на её заголовок;
- поиск по CAN ID, данным и расшифровке;
- фильтры по CANopen-типу, номеру узла и изменению данных;
- статистика частоты и периода для каждого CAN ID;
- расшифровка NMT, heartbeat, EMCY и основных SDO-команд;
- представление 32-битных SDO-значений как HEX, `uint32`, `int32` и `float32`;
- экспорт текущей отфильтрованной выборки в CSV (UTF-8 с BOM, разделитель `;`).

Для больших записей в таблице показываются первые 50 000 отфильтрованных
строк, но CSV-экспорт содержит всю выборку.
